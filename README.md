### 👋 About me · 關於我

- 🎓 I study **computer science and psychology** — I want to know *why* an interface works, not only *that* it works.
  <br/><sub>我同時念 **資工與心理學**，想知道一個介面「為什麼有效」，而不只是「它能用」。</sub>
- 🧠 My focus is **HCI / UX engineering**: usability, behavioral design, and user research turned into shipped products.
  <br/><sub>主攻 **HCI／使用者體驗工程**：把可用性、行為設計與使用者研究，實際做成產品。</sub>
- 🛠️ I mostly build on the **web** — React, TypeScript, and whatever gets the prototype in front of a real user fastest.
  <br/><sub>主要在 **Web** 上開發，用 React 與 TypeScript，怎麼最快讓真人用到原型就怎麼做。</sub>
- 🌱 Currently learning **design systems, accessibility (a11y), and experiment design**.
  <br/><sub>目前正在學 **設計系統、無障礙設計、實驗設計**。</sub>
- 🤝 Open to **internships** and to collaborating on anything that sits between people and screens.
  <br/><sub>正在找 **實習機會**，也歡迎任何「人與螢幕之間」的合作提案。</sub>
